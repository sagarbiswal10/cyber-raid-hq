# Cyber Raid Defense

Build Cyber Raid, a modern browser-based 3D cybersecurity game using React, TypeScript, React Three Fiber (Three.js), Tailwind CSS, and MediaPipe Hands. The player is a cybersecurity analyst defending a futuristic Security Operations Center (SOC) from fictional cyberattacks like malware, phishing, and data exfiltration. Create an immersive 3D environment with computers, servers, routers, and animated network connections where random attacks occur and spread if not contained. Support both Mouse Mode and Camera Mode, with MediaPipe hand gestures (Point = Select, Pinch = Investigate, Swipe = Isolate, Open Palm = Activate Firewall). Include a mission timer, threat level, network integrity, firewall energy, score, combo multiplier, player ranks, mission results, and a leaderboard using localStorage. Design the game with a sleek cyberpunk UI, smooth animations, immersive sound effects, modular architecture, and responsive performance, ensuring the gameplay is engaging, competitive, and educational while keeping all cybersecurity scenarios purely fictional.
